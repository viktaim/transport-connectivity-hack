# Черновик индикаторов Red Wings

Дата проверки: **08.11.2026**, часовой пояс Europe/Moscow. Ветка: `yulia/weights`.
Таблица: [redwings_indicators_draft.csv](redwings_indicators_draft.csv).
Это материал для ручной проверки. Все 36 строк имеют `review_status=pending`.
Веса и расчетные модули не изменялись. Данные не переносились в итоговые наборы.

## Наполнение и смысл полей

Одна строка — один индикатор одного города. 12 городов × 3 индикатора = 36 строк.

| Индикатор | Заполнено | Пусто (null) | Проверяет |
|---|---:|---:|---|
| airport_pax | 10 | 2 | Настя |
| competitor_hub | 4 | 8 | Никита |
| redwings_presence | 8 | 4 | Никита |
| Всего | 22 | 14 | |

22 — число значений-кандидатов, а не число окончательно подтвержденных командой показателей.
Из них 21 положительное значение и один ноль. Ноль только у `redwings_presence`
Ростова-на-Дону на основании уведомления аэропорта о прекращении приема и выпуска ВС.
Для `airport_pax` нулей нет.

`value` пустое означает неизвестное значение. `year` у пассажиропотока — год измерения,
у бинарных индикаторов — год, к которому относится свидетельство. `checked_at` — дата чтения,
она не продлевает срок актуальности старого сообщения. Пустой `year` у null означает,
что период нужного подтверждения не установлен. `reviewer` — назначенный проверяющий,
а не отметка о выполненной проверке.

CSV имеет кодировку UTF-8, разделитель — запятая, десятичные дроби в `value` отсутствуют.
В Excel его можно импортировать через «Данные → Из текста/CSV», выбрав UTF-8 и запятую.
Округленные числа переведены в пассажиров с точностью исходной публикации;
целочисленная запись не означает точность до одного пассажира.

Где доступна только перепечатка сообщения оператора, это явно обозначено.
Прямые ссылки на посты Telegram получены из прочитанных веб-лент; ссылки на сами
ленты также сохранены в комментариях, поскольку отдельные посты не всегда раскрывают текст без приложения.

## Проверки файла

Проверены 36 строк, 12 городов, ровно три индикатора у каждого города,
уникальность пар `city + indicator`, типы и допустимые значения, наличие URL и года
у заполненных значений, комментариев и назначенных проверяющих.
У всех строк `pending`. Проверка структуры не заменяет ручную проверку источников.

Воспроизводимая проверка из корня репозитория в PowerShell:

```powershell
$rows = @(Import-Csv data/drafts/redwings_indicators_draft.csv -Encoding UTF8)
$indicators = @('airport_pax','competitor_hub','redwings_presence')
if ($rows.Count -ne 36) { throw 'Expected 36 rows' }
if (@($rows | Group-Object city).Count -ne 12) { throw 'Expected 12 cities' }
if (@($rows | Group-Object city,indicator | Where-Object Count -ne 1).Count) { throw 'Duplicate pair' }
foreach ($city in ($rows | Group-Object city)) {
    if ($city.Count -ne 3 -or (Compare-Object $indicators @($city.Group.indicator))) { throw 'Indicator set' }
}
foreach ($r in $rows) {
    if ($r.review_status -ne 'pending' -or -not $r.comment -or -not $r.reviewer) { throw 'Review fields' }
    if ($r.value -ne '') {
        if ($r.year -notmatch '^20[0-9]{2}$' -or $r.source -notmatch '^https://') { throw 'Missing provenance' }
        if ($r.indicator -eq 'airport_pax' -and $r.value -notmatch '^[0-9]+$') { throw 'Pax type' }
        if ($r.indicator -ne 'airport_pax' -and $r.value -notin @('0','1')) { throw 'Binary type' }
    }
}
'CSV validation passed'
```
